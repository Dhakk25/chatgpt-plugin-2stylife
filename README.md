# ChatGPT Plugin – 2Stylife AI Assistant

This is an OpenAI ChatGPT plugin that allows users to explore featured products, Instagram highlights, and Facebook updates from [2stylife.com](https://2stylife.com) — a curated fashion and lifestyle destination.

---

## 🔗 Features

- 👜 Get product links from the 2Stylife store
- 📸 Show latest Instagram posts
- 📘 View Facebook updates from the official fanpage

---

## 📁 Plugin Endpoints

| Endpoint           | Description                        |
|--------------------|------------------------------------|
| `/products`        | Returns featured product links     |
| `/instagram-posts` | Fetches Instagram post highlights  |
| `/facebook-posts`  | Lists recent Facebook fanpage posts|
